# 创新一：结构感知的分组密码神经网络区分器匹配策略

## 1. 创新点定位

本创新点不表述为“首次提出神经网络区分器”，也不表述为“首次提出通用神经区分器平台”。已有工作已经覆盖 SPECK、SIMON、PRESENT、TEA、AES avalanche dataset 等多类对象，并出现了密码无关训练流水线。因此，本论文的创新一应收敛为：

> 面向 ARX、SPN、Feistel-like 等不同分组密码结构，提出一套结构感知的神经网络区分器匹配策略。在统一数据生成、统一训练预算、统一评价指标和统一统计检验协议下，比较不同网络架构对不同密码结构的适配性，形成“密码结构特征 - 网络架构偏好 - 临界轮数”的经验映射关系。

这一定义的价值在于：它避开“通用流水线已有人做过”的风险，把贡献落在“结构特征驱动的横向比较和可复现实验协议”上。

## 2. 相关工作归纳

| 文献 | 主要对象 | 方法要点 | 对创新一的启发 |
|---|---|---|---|
| Gohr, CRYPTO 2019 | SPECK32/64 | 使用深度残差网络构造神经差分区分器，并用于 reduced-round key recovery | ResNet/bit-slice CNN 是 ARX 类密码的强基线 |
| Bellini & Rossi, SAI 2021 | TEA、RAIDEN | 比较深度学习区分器与传统区分器，扩展到更大分组/密钥的 ARX-like 算法 | 仅在 ARX 家族内扩展还不够，需要跨结构比较 |
| Benamira et al., EUROCRYPT 2021 | SPECK | 分析 Gohr 区分器到底学习了什么，指出其与差分分布及中间轮分布相关 | 架构选择不能只看精度，还要记录可解释证据 |
| Bao et al., ASIACRYPT 2022 | SPECK、SIMON | 强化差分-神经密码分析，改进 key recovery，并比较神经/传统区分器 | ARX/AND-RX 类结构适合保留为第一阶段复现实验 |
| Gohr, Leander & Neumann, ePrint 2022/1521 | 多个分组密码 | 系统评估 differential-neural distinguishers，强调可比性、分布距离、错误实验结论纠正 | 需要统一评价协议和多种子统计，不能只报单次精度 |
| Ebrahimi et al., FPS 2022 | SPECK32/64 | 通过 bit selection 和 partial ML distinguisher 降低成本 | 结构匹配还应比较输入表示和有效比特选择 |
| Hambitzer et al., CT-RSA 2023 | SPECK、AES avalanche dataset 等 | NNBits 用 ensemble 做 bit profiling，并与 NIST STS 比较 | 可以把 bit-level profiling 作为后续解释模块 |
| Bellini et al., ToSC 2023 | SPECK、SIMON、PRESENT、TEA、GIMLI 等 | 自动搜索输入差分，并提出 cipher-agnostic DBitNet | 本文不能声称“首次通用”，应把 DBitNet 作为通用基线 |
| Gérault et al., ePrint 2024/1300 | 5 年神经差分密码分析综述 | 梳理 178 篇相关出版物，指出可比性和 scaling 是核心挑战 | 创新一正好回应“可比性”问题 |

## 3. 结构特征建模

创新一把密码算法抽象为结构特征向量，而不是只使用算法名称：

| 结构 | 代表算法 | 结构特征 | 预期可学习模式 |
|---|---|---|---|
| ARX | SPECK32/64 | modular addition、rotation、xor、carry propagation、word parallelism | 模加进位导致的局部/跨位相关性，旋转异或导致的位位置混合 |
| SPN | PRESENT-80、reduced AES | sbox layer、permutation/linear layer、sbox locality、bit permutation | S 盒局部非线性模式，置换/线性扩散形成的局部到全局传播 |
| Feistel-like | SM4、DES/TWINE 可选 | unbalanced state update、round recurrence、sbox + linear diffusion | 左右/字状态迭代依赖，轮函数递推关系 |

SM4 在论文中建议写作 Feistel-like 或 unbalanced Feistel-like，不建议简单归为普通 SPN。它的轮函数内部包含 S 盒和线性变换，但整体状态更新方式与 AES/PRESENT 这类典型 SPN 不同。

## 4. 网络候选集

| 网络 | 主要用途 | 对应结构假设 | 论文中的角色 |
|---|---|---|---|
| ResNet-BitSlice | Gohr 风格残差卷积区分器 | 适合 ARX 的位切片输入、模加进位和旋转异或特征 | ARX 强基线 |
| DBitNet-DilatedCNN | 密码无关扩张卷积 | 适合做统一输入和宽感受野比较 | 通用基线 |
| CNN-SBoxLocal | 小型局部卷积 | 适合 S 盒局部非线性与轻量级 SPN | SPN 低成本基线 |
| RNN-LSTM-RoundSeq | 轮序列建模 | 适合中间轮 trace 或 Feistel-like 状态递推 | Feistel-like/轮间扩展候选 |
| Transformer-Encoder | 全局注意力 | 适合长程扩散建模但成本较高 | 高成本消融，不作为首选 |
| MLP-Baseline | 全连接基线 | 无显式结构先验 | 对照组 |

## 5. 匹配策略定义

当前版本采用可解释的“结构重合 + 文献证据”规则评分，而不是直接声称自动学习最优架构：

```text
score(cipher, network)
  = 3 * |cipher_traits ∩ network_strengths|
    + 2 * literature_weight(cipher, network)
    - compute_penalty(network)
```

其中 compute penalty 取值为 low = 0、medium = 1、high = 3。`literature_weight` 来自本地论文库中提炼出的规则，例如 Gohr 2019 与 Benamira 2021 支撑 SPECK/ARX 的 ResNet-BitSlice，Jain 2020/2021 与 SPN 框架支撑 PRESENT/SPN 的局部 CNN，DBitNet 2023 支撑跨结构的 dilated CNN 通用基线。该评分不是最终实验结论，而是用于生成候选优先级；最终论文结论必须由训练结果验证。

当前规则给出的首选候选为：

| 密码 | 结构 | 第一候选 | 第二候选 |
|---|---|---|---|
| SPECK32/64 | ARX | ResNet-BitSlice | DBitNet-DilatedCNN、MLP-Baseline |
| PRESENT-80 | SPN | CNN-SBoxLocal / DBitNet-DilatedCNN | 视轮数和训练预算做并列比较 |
| SM4 | Feistel-like | CNN-SBoxLocal / DBitNet-DilatedCNN | RNN-LSTM-RoundSeq 作为轮序列消融候选 |

注意：这张表只是“实验优先级表”，不是最终性能结论。最终论文表格应替换为真实训练结果。

### 5.1 结构感知专家融合模型

在结构感知匹配基础上，当前代码进一步加入结构感知专家混合模型 SA-MoE。它不再只为每种密码人工选择一个网络，而是将多个专家网络按结构特征进行融合：

```text
z_i = E_i(x), i = 1,...,K
alpha = Gate(s)
z = sum_i alpha_i * z_i
y_hat = sigmoid(z)
```

其中 `x` 是 `C || C' || (C xor C')` 等密文对输入表示，`s` 是由 `CipherProfile` 和轮数生成的结构特征向量，`E_i` 是专家网络。当前专家集合包括 ResNet-BitSlice、DBitNet-DilatedCNN、CNN-SBoxLocal 和 MLP-Baseline。

当前支持三种 gate：

| gate | 含义 | 论文角色 |
|---|---|---|
| `moe_uniform` | 所有专家等权融合 | 普通 ensemble 对照 |
| `moe_hard` | 按 ARX、SPN、Feistel-like 使用固定结构先验权重 | 结构先验专家融合 |
| `moe_soft` | 用小型 MLP 从结构特征学习专家权重 | 可训练结构门控模型 |

硬门控先验为：

```text
ARX          -> ResNet 0.55, DBitNet 0.30, CNN 0.10, MLP 0.05
SPN          -> ResNet 0.10, DBitNet 0.45, CNN 0.40, MLP 0.05
Feistel-like -> ResNet 0.30, DBitNet 0.50, CNN 0.15, MLP 0.05
```

第一版 SA-MoE 仍采用单密码实验输入宽度，即 SPECK、PRESENT、SM4 分别在自己的输入维度下训练 MoE；跨密码混合 batch、padding/mask 或 adapter 统一编码留作后续扩展。因此当前 MoE 适合作为“结构专家融合是否有价值”的 screening，而不是完整跨结构统一模型的最终形态。

## 6. 实验协议

### 6.0 文献差分配置

为了避免消融实验使用任意默认差分，当前代码将文献中使用或贴近文献设置的输入差分显式登记为 profile，并写入 JSONL/CSV 结果：

| 密码 | profile | 差分设置 | 来源与说明 |
|---|---|---|---|
| SPECK32/64 | `speck32_gohr2019` | `0x0040/0000`，在本仓库 `(x, y)` 编码下为 `0x00400000` | Gohr 2019 的 SPECK32/64 神经区分器设置 |
| PRESENT-80 | `present_wang_jain2021` | `0x0700000000000700`、`0x7000000000007000`、`0x0070000000000070`、`0x0007000000000007` | Wang 高概率差分，经 Jain/Kohli/Mishra 2020/2021 PRESENT 神经区分器工作采用或讨论 |
| SM4 | `sm4_yu2023_conv_resnet` | `(0x00000000, 0x00000000, 0x00000000, 0x00000001)` | Yu/Wu/Zhang 2023 SM4 卷积残差网络区分器设置 |
| SM4 | `sm4_li_sun_2025_19r_family` | `(a''0, e793932d, 6fb9b98f, 882a2a9e)` 形式的受约束差分族 | Li/Sun 2025 的高轮传统差分族；当前只登记，不作为固定神经输入差分使用 |

运行时可以通过 `--difference-profile` 和 `--difference-member` 指定；由 `build_innovation_one_matrix.py --top-k` 生成的推荐计划也会自动写入对应 profile。结果汇总保留 `difference_profile`、`difference_member`、`difference_source` 字段，保证不同文献差分不会在消融表中混合。

### 6.1 数据集构造

每个实验任务采用二分类区分器设置：

- 正样本：固定输入差分下的明文对经过 r 轮 reduced-round cipher 得到的密文对。
- 负样本：同维度随机密文对，或随机输入差分生成的密文对。
- 输入表示：当前支持 `C || C'` 和 `C || C' || (C xor C')` 两类特征编码，后者用于显式暴露密文对差分位。
- 划分：train/valid/test = 8:1:1。
- 密钥策略：训练集与测试集必须至少做 cross-key 测试，避免固定密钥过拟合。
- 随机种子：每组实验至少 5 个种子，报告均值和标准差。

### 6.2 评价指标

| 指标 | 定义 | 论文作用 |
|---|---|---|
| Accuracy | 区分正确率 | 基础性能指标 |
| Calibrated Accuracy | 在验证集上选择最佳阈值后的准确率 | 避免固定 0.5 阈值掩盖可排序信号 |
| AUC | 阈值无关区分能力 | 减少单一阈值偏差 |
| Advantage | `2 * accuracy - 1` | 与密码区分优势表述更接近 |
| Calibrated Advantage | `2 * calibrated_accuracy - 1` | 对应校准阈值下的区分优势 |
| Critical Round | 精度接近 0.5 或 advantage 接近 0 的轮数 | 衡量随机化临界轮 |
| Data Complexity | 达到固定精度所需样本量 | 比较样本效率 |
| Training Cost | 参数量、训练时间、显存或 FLOPs | 支撑工程可用性 |
| Stability | 多种子均值/方差 | 避免偶然结果 |
| Cross-key Generalization | 未见密钥测试表现 | 区分结构学习与记忆训练 |

### 6.3 消融实验

至少做三类消融：

1. 去掉结构感知匹配：所有密码统一用同一个网络。
2. 去掉结构输入表示：例如 ARX 不用 bit-slice/word-aware 表示。
3. 去掉成本约束：比较 Transformer 是否值得作为高成本候选。
4. 替换输入差分：比较默认差分与文献差分，PRESENT 还需要比较 `present_wang_jain2021` 的四个 member。

### 6.4 当前 screening 结果

已完成一组 GPU 小规模真实训练，用于验证实验闭环与差分配置可行性。该结果使用 `ciphertext_pair_xor_bits`、2 个随机种子、每类 4096 或 8192 样本，不能作为超越前沿工作的声明，只能作为后续扩样本/扩种子的依据。

| 密码与差分 | 轮数范围 | 主要观察 |
|---|---|---|
| SPECK32/64 `speck32_gohr2019` | 5-7 轮 | 5 轮有明显信号，DBitNet/ResNet/CNN calibrated accuracy 约 0.665-0.686；6 轮弱信号约 0.519-0.526；7 轮接近随机。该结果说明差分方向修正后实验可用，但当前轻量模型不是 Gohr 论文同款大模型/大样本复现。 |
| PRESENT-80 `present_wang_jain2021` member 0 | 4-6 轮 | 4 轮有明显信号，DBitNet calibrated accuracy 约 0.671，CNN 约 0.652；5 轮弱信号约 0.54；6 轮接近随机。 |
| PRESENT-80 四个 member 消融 | 4-5 轮 | member 0/2/3 明显强于 member 1；4 轮 DBitNet 整体略优于 CNN，支持将差分 member 纳入消融变量。 |
| SM4 `sm4_yu2023_conv_resnet` | 3-6 轮 | 3 轮几乎完全可区分；4 轮 DBitNet calibrated accuracy 约 0.639，ResNet 约 0.626，CNN 约 0.515；5/6 轮接近随机。适合写成扩散增强后结构信号快速衰减，而不是高轮突破。 |

下一步如果要冲论文主表，应把每类样本数提升到至少 `2^18` 或 `2^20` 量级、种子提升到 5 个以上，并补 cross-key 测试与训练成本统计。

## 7. 论文可写贡献

建议在论文中这样写创新一：

> 针对现有神经网络区分器多面向单一密码或单一结构优化、不同实验之间评价标准不统一的问题，本文提出结构感知的分组密码神经网络区分器匹配策略。该策略首先从轮函数、扩散机制、非线性组件和状态更新方式中抽取密码结构特征，再根据网络架构的特征提取偏好生成候选匹配关系，最后在统一数据生成、统一训练预算和统一评价指标下验证不同结构密码与神经网络架构之间的适配规律。该方法既保留 Gohr 风格残差区分器和 DBitNet 等已有强基线，又通过横向比较 ARX、SPN、Feistel-like 结构形成可复现实验协议，为分组密码智能化检测系统提供模型选择依据。

## 8. 当前仓库交付

已实现的最小代码框架：

- `src/blockcipher_ai_eval/innovation_one.py`：结构特征、网络特征、文献证据规则、匹配评分、推荐实验矩阵生成。
- `src/blockcipher_ai_eval/structure_features.py`：将密码结构和轮数编码为 SA-MoE gate 输入向量。
- `src/blockcipher_ai_eval/experiments/difference_profiles.py`：登记 SPECK、PRESENT、SM4 的文献差分 profile。
- `src/blockcipher_ai_eval/models/`：MLP、CNN-SBoxLocal、ResNet-BitSlice、DBitNet-DilatedCNN、RNN-LSTM-RoundSeq、Transformer-Encoder 候选模型入口。
- `src/blockcipher_ai_eval/models/structure_moe.py`：结构感知专家融合区分器，支持 uniform、hard、soft 三种 gate。
- `tests/test_innovation_one.py`：验证 ARX/SPN/Feistel-like 的候选匹配、实验矩阵和论文句子生成。
- `experiments/build_innovation_one_matrix.py`：生成全量 CSV 实验矩阵，或生成 top-k 文献推荐矩阵。
- `experiments/run_innovation_one_matrix.py`：既支持手工 cipher/model 矩阵，也支持读取 top-k 推荐 CSV 逐行训练，并支持文献差分 profile。
- `experiments/summarize_innovation_one_results.py`：汇总多种子结果，并保留架构排名、匹配分数、文献证据、差分来源和校准指标字段。

运行：

```bash
python -m pytest -q
python experiments/build_innovation_one_matrix.py --rounds 3 4 5 6 7 --seeds 0 1 2 3 4
python experiments/build_innovation_one_matrix.py --top-k 2 --rounds 3 4 5 --seeds 0 1 2
python experiments/run_innovation_one_matrix.py --plan outputs/innovation_one_experiment_matrix.csv --epochs 5
python experiments/summarize_innovation_one_results.py --input outputs/innovation_one_matrix_results.jsonl --output outputs/innovation_one_summary.csv
```

默认会生成：

```text
outputs/innovation_one_experiment_matrix.csv
```
